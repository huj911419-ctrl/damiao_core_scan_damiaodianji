# DM-J4310-2EC V1.1 实机 CAN ID 探测结果（2026-11-05）

## 扫描结果（实际电机回复，非默认参数假设）
- 控制板：达妙 DM-MC02（SWD 读取到 STM32H7 Cortex-M7）。
- 扫描固件：`build/j4310-v11-scan/J4310-v11-id-scan.hex`。
- 固件 SHA256：`797ad27d9697a07c4b9c8b59690fcef22d98f0182f4e470ddf26f9b698f3d7e6`。
- 主机端口：控制板 USB CDC `/dev/ttyACM1`，**非** DAPLink 的 `/dev/ttyACM0`。
- 扫描 CAN2 收到两条只读寄存器的有效响应：
  - `CAN2 FOUND ESC_ID=0x000 response=0x010`
  - `CAN2 FOUND ESC_ID=0x000 MST_ID=0x010 (read-register reply)`
- **目标电机在 CAN2：ESC_ID = 0x000（十进制 0），MST_ID = 0x010（十进制 16）。**
- CAN1 在此次扫描观察时收到的报文数量为 0，并不证明 CAN1 硬件故障或完全没有其他设备。

## 控制与反馈分开
- `ESC_ID` 是该电机在查询中回应的接收命令 ID；`MST_ID` 对应反馈身份 ID。两者不要混用。
- 这次只发了 CAN 0x7FF / 0x33 / RID7、RID8 只读寄存器请求，没有发送电机使能、转矩、位置、速度或保存配置指令。
- 实测收到 `0x010` CAN 应答 ID；控制 ID 由读回寄存器确认，不能将其直接设为反馈 ID。

## 电源结束状态
- 扫描过程中明确通过 `POWER ON WIRED` 将两个板载受控24V GPIO 置高，终端查询 `PWR=ON`。
- 扫描得到 ID 后已经发送 `POWER OFF`，终端再次查询 `PWR=OFF`：
  `PWR=OFF CAN1:rx=0 ESC=?0x000 MST=?0x000 CAN2:rx=2 ESC=0x000 MST=0x010`
- **注意：GPIO 软件状态不代表外部24V电源真正断开。拆接线前仍必须实际切断电源并测量。**
